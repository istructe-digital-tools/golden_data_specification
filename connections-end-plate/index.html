End plate

Page 43 of 56 - Connections

This section defines engineering properties for simplified structural connection representations within the BIM model. Connections are typically modelled as proxy elements with associated property sets that capture plate geometry, bolt arrangements, and related parameters. This approach retains essential design and coordination information while avoiding unnecessary modelling detail.

This section defines properties for end plate connections between steel members. The information captures plate thickness, bolt group geometry, edge and end distances, and pitch values used to describe the connection layout for design coordination and documentation.

Properties are recorded in the connection local coordinate system, consistent with the illustration. Bolt grade and material data are recorded under "Fasteners - Bolts".

These properties apply to simplified connection objects (for example, IfcBuildingElementProxy) with associated custom or project-specific property sets, as described in the connection property sets overview.

Layout properties are custom IfcPropertySingleValue definitions on IfcBuildingElementProxy (or equivalent connection proxy). Length fields use IfcPositiveLengthMeasure; Double Sided uses IfcBoolean. Values are expressed in the proxy object's local placement coordinate system as exported in the IFC file.

note

Bolt Group Depth (label A) is measured from the top flange or designated edge per the Definition column. Bolt Guage (label F) is the spacing between bolt columns on either side of the web. Edge Distance and End Distance are to bolt centre unless the Definition states otherwise. Horizontal Pitch and Vertical Pitch are centre-to-centre bolt spacing. Plate Thickness is the end plate thickness. Double Sided: true when plates occur on both sides of the connected element. For bolt grade and material properties, see "Fasteners - Bolts".
