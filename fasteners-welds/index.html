Welds

Page 41 of 56 - Fasteners

This section defines properties for structural fasteners modelled or referenced within the BIM environment. Fastener information supports connection design verification, fabrication coordination, and quality assurance without requiring every bolt, weld, or stud to be modelled as discrete geometry. Properties are grouped to align with IFC fastener and material property sets.

This section defines weld-related properties used to describe welded joints within structural connections. The information captures weld type, process, geometry, continuity, and certification data required for design coordination, fabrication planning, and quality verification.

At design stage, weld type and nominal throat thickness usually convey structural intent; at construction stage, process name, continuity, and certification align with the qualified welding procedure.

These properties are typically applied to connection proxy elements or weld occurrence definitions rather than to fully modelled weld solids.

Weld properties are assigned to connection proxies or IfcFastener entities. Use a _Weld suffix on extended Psets where weld data is split from base material definitions. Weld Certificate should use IfcDocumentReference. Weld Continuity and Weld Pattern Staggered use IfcBoolean. Throat and width fields use IfcPositiveLengthMeasure.

note

Weld Type uses structural terminology (for example, fillet or butt). Nominal Throat Thickness and Weld Width are length measures per the diagram and project units. Weld Standard references the fabrication code (for example, EN 1090). Process Name identifies the qualified process (for example, GMAW) from the WPS. Weld Certificate links to the procedure qualification or inspection record.
