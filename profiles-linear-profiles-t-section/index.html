Linear profiles - T-section

Page 32 of 56 - Profiles

This section defines geometric parameters for linear structural section profiles used within the BIM model. These parameters describe the cross-sectional shape of elements and are used consistently across structural components to ensure accurate representation of section geometry for analysis, fabrication, and documentation purposes.

This section defines the geometric parameters for T-section profiles. These parameters describe flange width, overall depth, web and flange thicknesses, and optional edge and fillet radii.

The values are mapped to the IFC entity IfcTShapeProfileDef and should be interpreted within the local profile coordinate system.

Parameters map to attributes of IfcTShapeProfileDef. Optional attributes (WebSlope, FlangeEdgeRadius, WebEdgeRadius) may be omitted when not supported on export. Length fields use IfcPositiveLengthMeasure in the profile Position coordinate system.

Fillet RadiusOptional
The fillet radius is the internal curved transition between the web and flange of the T‑section. It reduces stress concentrations at the junction and improves load transfer between the web and flange.
ExistingIfcTShapeProfileDef → FilletRadiusIfcTShapeProfileDef10 [mm]
Flange Edge RadiusOptional
The flange edge radius is the rounded external corner along the edge of the flange. It helps reduce local stress concentrations and improves durability and resistance to damage during handling or service.
ExistingIfcTShapeProfileDef → FlangeEdgeRadiusIfcTShapeProfileDef6 [mm]
Web Edge RadiusOptional
The web edge radius is the rounded external edge along the vertical web of the T‑section. It reduces sharp edges, improving stress distribution and contributing to safer handling and fabrication.
ExistingIfcTShapeProfileDef → WebEdgeRadiusIfcTShapeProfileDef5 [mm]
Web SlopeOptional
Web slope refers to any taper across the thickness of the web, typically introduced during the rolling or manufacturing process. It affects connection detailing and must be considered when fitting or joining elements to the web.
ExistingIfcTShapeProfileDef → WebSlopeIfcTShapeProfileDef8 [O]
Flange SlopeOptional
Flange slope is the taper across the thickness of the flange, commonly resulting from the rolling process. It influences how loads are transferred through connections and must be accounted for in fabrication and assembly.
ExistingIfcTShapeProfileDef → FlangeSlopeIfcTShapeProfileDef8 [O]
note

Width, Depth, Web Thickness, and Flange Thickness follow diagram labels. Fillet Radius = web-to-flange root radius. Flange Edge Radius and Web Edge Radius are optional. Web Slope uses the ratio or angle convention declared in the project IFC export specification.
