Timber - Design stage

Page 17 of 56 - Materials

This section defines how material information is captured within the BIM model using structured property sets. Material data provides the physical, mechanical, and performance characteristics required for analysis, design verification, fabrication, and lifecycle asset management. These properties should be applied consistently to ensure that material behaviour is correctly represented across all relevant structural elements.

This section defines the required material properties for structural timber at the design stage. The information captures strength classification, moisture conditions, density, and mechanical behaviour used to support structural analysis, code compliance, and specification of timber products.

At design stage, strength grade and moisture class define the assumed performance envelope for analysis, not values from a specific delivery batch. For laminated or engineered products, layer thickness and direction reflect anisotropic behaviour relative to grain direction.

The information is primarily mapped to IFC material property sets such as Pset_MaterialWood, Pset_MaterialCommon, and Pset_MaterialMechanical.

Properties are assigned to IfcMaterial through Pset_MaterialWood, Pset_MaterialCommon, and Pset_MaterialMechanical. Strength Grade, Moisture Class, and Layer Thickness & Direction are typically IfcLabel. Mechanical properties use the typed measures in the Definition column; use IfcReal only as a documented fallback with units via IfcUnitAssignment.

note

Strength Grade uses the project classification notation (for example, C24 or GL24h). Moisture Class is the design service class (for example, Service Class 2), not a measured moisture content. Layer Thickness & Direction describes ply lay-up for engineered timber where applicable; omit or mark N/A for solid sawn sections. Bending Strength, Tensile Strength, and Tensile Strength Perpendicular map to IfcPressureMeasure where supported.
